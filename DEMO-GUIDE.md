## Before recording
- Run `node --test`; check server and Gemini availability.
- Rehearse file selection and date entry. Enter values visibly, then pause briefly.
- If AI latency makes the rehearsal exceed 3:45, shorten narration and visual pauses; do not imply saved or prerecorded responses are live.
- Keep API keys, environment files, and real guest information off screen.
- Check the final recording duration is strictly below 4:00.
- Upload yourself to an unlisted YouTube video or Google Drive with Anyone with the link access. Verify playback in a private/incognito window without signing in.
